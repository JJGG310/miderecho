# Identidad: el búho de MiDerecho

Mascota del sistema: un búho con pañoleta verde y la balanza de la justicia. Personalidad: **curioso, amigable, sabio y acompañante**.

- `imagen-referencia.jpeg`: hoja original del personaje (poses, personalidad y valores).
- `video-referencia.mp4`: animación original (8 s: guiña, sonríe y saluda).
- `buho/`: poses recortadas con fondo transparente. `.webp` para la web (liviano) y `.png` para presentaciones y video.

| Archivo | Pose | Uso sugerido |
|---|---|---|
| `saludo` | Saluda y guiña | Bienvenida, inicio, landing |
| `ley` | Lee un libro con la balanza | "Qué dice la ley", derechos |
| `lupa` | Mira con lupa | Buscar, analizando el caso |
| `corazon` | Abraza un corazón | Éxito, caso resuelto, gracias |
| `pensando` | Duda con signo de pregunta | "No sé", ayuda, preguntas |
| `documento` | Muestra un documento | Documento listo |
| `computador` | Trabaja en el computador | El asistente está pensando |
| `avatar-curioso`, `avatar-amigable`, `avatar-sabio`, `avatar-acompanante` | Avatares en círculo | Perfil, asistente, estados |
| `buho-saluda.mp4` y `-poster.jpg` | Animación liviana sin audio | Landing y presentación |

Colores: verde de la pañoleta y de la app `#264933`, café del plumaje, crema de fondo `#fff5e4`.
